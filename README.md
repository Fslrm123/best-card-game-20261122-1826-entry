**Aetherfall Duels** — an original lane-duel card game. You are the Aetherbound, duelling the Voidwarden Malachai across three lanes. Summon creatures with Aether, wake them next turn, and strike the lane opposite — or the hero behind it. First to bring the other from 20 Life to 0 wins. Fourteen original cards (creatures and spells across four rarities), a greedy AI opponent, synthesized sound, zero network requests, zero external assets: every card's art is inline SVG drawn by the code itself.
